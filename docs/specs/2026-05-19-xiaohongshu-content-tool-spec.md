# Product Spec: 小红书铝单板内容运营工具

## 1. 产品概述
- **解决的问题**：铝单板销售在小红书做内容引流，面临选题混乱、AI 文案质量不稳定、发布排期无管理、数据复盘靠手工等痛点
- **目标用户**：个人自用（铝单板销售 + 视频设计师），B 端内容引流
- **核心价值**：一套完整的 AI 驱动内容生产流程，从选题到发布到数据复盘，全流程管理

## 2. 功能需求

### 2.1 选题管理
- **功能描述**：创建、编辑、删除选题，标注状态（待写/写作中/已完成/已发布），支持标签分类
- **用户场景**：用户浏览行业动态后随手记录选题灵感，后续安排到写作计划中
- **验收标准**：
  - 支持选题的增删改查
  - 支持标签/分类筛选
  - 支持按状态看板视图切换
  - AI 可基于用户输入的行业关键词智能推荐选题

### 2.2 AI 文案生成与编辑
- **功能描述**：内置科学的 AI 内容生产流程，自动生成小红书爆款文案
- **用户场景**：用户选中一个选题，配置 Prompt 参数，AI 生成标题+正文+标签
- **验收标准**：
  - 内置铝单板行业 Prompt 模板（知识科普/视觉展示/客户问答）
  - 支持文案结构：痛点场景 + 解决方案 + 效果证明
  - 支持多版本生成（A/B 对比）
  - 生成结果可直接编辑修改
  - 支持 AI 质量增强（反常识表述、权威背书、广告法合规检查）
  - 文案长度可配置（默认 ≤300 字）
  - Emoji 数量可配置（默认 3 个）
  - 标签数量可配置（默认 5 个）

### 2.3 图片处理
- **功能描述**：上传/管理配图，支持图片裁剪、尺寸调整
- **用户场景**：用户将工厂实拍图/设计效果图上传，配合文案一起使用
- **验收标准**：
  - 支持图片上传（本地文件选择）
  - 支持图片预览
  - 支持图片基础处理（裁剪/缩放）
  - 支持导出图片（适配小红书尺寸 3:4）

### 2.4 排期发布
- **功能描述**：日历视图展示发布计划，支持一键复制文案/下载图片
- **用户场景**：用户将写好的内容安排到特定日期发布，到期提醒
- **验收标准**：
  - 日历视图显示每日发布计划
  - 支持拖拽调整发布日期
  - 支持一键复制文案到剪贴板
  - 支持一键下载配图
  - 半自动发布流程（复制后跳转小红书发布页）

### 2.5 数据复盘
- **功能描述**：发布后数据录入与分析，生成可视化图表
- **用户场景**：用户发布笔记后记录/自动同步数据，分析内容表现
- **验收标准**：
  - 支持手动录入数据（点赞/收藏/评论/阅读量）
  - 自动模式：如接入小红书 API，自动拉取数据
  - 数据图表：趋势图、对比图、内容表现排行
  - 内容诊断建议：基于数据给出优化建议

### 2.6 素材库管理
- **功能描述**：管理图片素材和文案片段，支持快速复用
- **用户场景**：用户收藏常用话术、金句、案例描述，写作时快速插入
- **验收标准**：
  - 图片素材分类管理（工厂实拍/案例图/设计图等）
  - 文案片段收藏（金句/数据/案例描述）
  - 支持标签搜索
  - 写作时一键插入素材

### 2.7 AI Prompt 模板管理
- **功能描述**：自定义、编辑、保存 Prompt 模板
- **用户场景**：用户根据使用反馈优化 Prompt，保存为模板复用
- **验收标准**：
  - 内置 3+ 铝单板行业 Prompt 模板
  - 支持创建自定义模板
  - 支持模板变量占位（如 `{选题}` `{产品卖点}` `{目标客户}`）
  - 支持模板测试（即时预览生成效果）

## 3. 非功能需求
- **性能要求**：AI 生成文案响应时间 ≤15 秒（取决于模型 API 响应）
- **安全要求**：OpenRouter API Key 仅存储在服务端，不暴露在前端
- **兼容性要求**：Chrome/Edge/Safari 最新版
- **离线可用性**：断网时可浏览已保存内容，AI 生成需联网

## 4. 技术约束
- **技术栈**：Next.js (App Router) + TypeScript + Prisma + SQLite
- **AI 接口**：OpenRouter API（免费模型）
- **数据存储**：SQLite 本地数据库文件
- **部署方式**：本地运行 `npm run dev`
- **UI 框架**：Tailwind CSS + shadcn/ui

## 5. 边界情况
- **小红书 API 权限不足**：数据复盘模块自动降级为手动录入模式，用户可后续补充 API Key 开启自动同步
- **AI 模型不稳定**：支持切换备用模型，生成失败时保留用户已填写的选题信息
- **数据库文件损坏**：支持 SQLite 文件备份/恢复
- **OpenRouter 免费额度用完**：提示用户配置备用 API 或手动编辑模式

## 6. 内容策略内置
- **内容比例**：70% 知识科普 + 20% 视觉内容 + 10% 客户问答
- **目标客户画像**：建筑装饰公司采购/设计师/工程承包商/装修公司
- **行业关键词**：铝单板、幕墙、氟碳喷涂、木纹转印、造型铝板、异形铝板
- **文案结构模板**：
  - 知识科普类：痛点场景 → 知识点拆解 → 避坑建议
  - 视觉展示类：效果对比 → 工艺解析 → 适用场景
  - 客户问答类：常见问题 → 专业解答 → 引导咨询

## 7. 成功标准
- 能完成一条内容从选题 → AI 生成 → 编辑 → 排期 → 发布 → 数据录入的完整闭环
- AI 生成的文案用户满意度 >50%（即至少一半的内容不需要大改就能用）
- 用户可独立使用，无需额外工具配合
