# Design Brief: 登录页 + 用户管理

## 1. 设计范围
新增登录页面和用户管理模块，其余页面无视觉变更。

## 2. 登录页

### 2.1 布局
- 居中卡片式布局，移动端全宽
- 背景：项目 violet 渐变 `bg-gradient-to-br from-violet-500 to-purple-600`
- 卡片：白色圆角 `rounded-2xl shadow-xl p-6 md:p-8 max-w-[400px] mx-auto`

### 2.2 元素
- Logo/标题："小红书运营工具" + 副标题"登录后继续"
- 邮箱输入框：`Input` 组件，placeholder "请输入邮箱"
- 发送验证码按钮：`bg-violet-600 text-white`，发送后变为倒计时 "60s 后重发"
- 验证码输入框：6 位数字，`Input` 组件，placeholder "请输入验证码"
- 登录按钮：验证码输入后自动验证，或手动点击"登录"

### 2.3 状态
- 邮件发送中：按钮 loading 状态
- 验证码错误：输入框下方红色提示 "验证码错误，请重试"
- 发送频率限制：5 次/小时，超出后提示 "发送过于频繁，请稍后再试"

## 3. 用户管理
- 在设置页新增"用户管理"卡片
- 用户列表：表格显示邮箱、注册时间、状态
- 添加用户：按钮 + 邮箱输入弹窗
- 移除用户：删除按钮 + 确认弹窗

## 4. 配色
延续项目 violet 色系：
- 登录背景：violet 渐变
- 主按钮：`bg-violet-600`
- 错误提示：`text-red-500`
- 卡片：`bg-white`

## 5. 响应式
- 移动端：登录卡片全宽，padding 减少
- 桌面端：登录卡片居中，最大宽度 400px
