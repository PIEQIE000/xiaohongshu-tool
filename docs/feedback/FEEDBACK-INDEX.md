# Feedback Index

反馈记录索引文件。每次用户给出修正意见或表达不满时，自动在此文件末尾追加记录。

## 反馈记录格式

```markdown
### 反馈 #N
- **时间**: YYYY-MM-DD HH:MM
- **场景**: [哪个 Skill/Phase/Task]
- **反馈内容**: [用户说了什么]
- **出现次数**: N
- **处理状态**: 待处理 / 已处理 / 已升级为规则
- **关联规则**: [如已升级为进化规则，关联到 EVOLUTION.md 条目]
```

## 使用说明

- 当检测到用户消息中包含以下信号时，自动记录反馈：
  - "你搞错了"、"不是这样"、"你又忘了"
  - "不对"、"错了"、"重新"、"改一下"
  - "这个不需要"、"多做了"、"漏了"
  - 任何表达修正或不满的关键词

- 同一条反馈（语义相同）出现 **3 次以上**时，提议升级为正式规则写入 `EVOLUTION.md`

- 每条进化建议都需要用户确认才会执行，绝不自动改规则
