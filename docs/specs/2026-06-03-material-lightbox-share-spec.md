# Product Spec: 素材库图片浏览器 + 分享

## 1. 产品概述
- 解决的问题：素材库中的图片无法放大查看，无法直接分享图片到微信/保存到手机
- 目标用户：铝单板销售从业者，需在手机上查看素材并分享给客户/同事
- 核心价值：快速浏览素材图片 + 一键分享到微信 + 保存到相册

## 2. 功能需求

### 2.1 图片浏览器（Lightbox）
- 功能描述：点击素材库任意图片进入全屏浏览模式，支持左右切换
- 用户场景：用户想仔细查看某张素材图片的细节，或翻阅素材库图片
- 交互方式：
  - 点击图片 → 全屏深色背景打开当前图片
  - 左右箭头按钮切换上一张/下一张
  - 手机端支持左右滑动手势切换
  - 点击背景空白处或关闭按钮退出
- 验收标准：
  - 点击图片能打开全屏浏览器
  - 左右箭头/滑动能切换图片
  - 第一张时左箭头不可用，最后一张时右箭头不可用
  - 关闭后回到素材库页面

### 2.2 系统分享（Web Share API）
- 功能描述：通过系统分享面板，将图片直接分享到微信等应用
- 用户场景：选中素材图片后，直接转发到微信客户或同事
- 交互方式：
  - 全屏浏览器内：底部工具栏有"分享"按钮
  - 素材库列表多选后：顶部"发送到手机"按钮改为"分享"按钮
  - 点击 → 调起系统分享面板（手机端显示微信、保存、邮件等）
- 技术实现：`navigator.share({ files: [...] })` 直接分享图片文件
- 验收标准：
  - 单张图片：全屏浏览时点击分享 → 系统分享面板弹出
  - 多张图片：多选后点击分享 → 系统分享面板弹出，包含所有选中图片
  - 桌面端不支持 Web Share API 时显示降级提示或下载按钮

### 2.3 下载/保存到相册
- 功能描述：直接下载图片到设备
- 用户场景：用户想保存图片到手机相册
- 交互方式：
  - 全屏浏览器内：底部工具栏有"下载"按钮
  - 点击 → 触发浏览器下载
- 验收标准：
  - 点击下载按钮 → 图片开始下载
  - 手机端下载后可在相册中看到

## 3. 非功能需求
- 性能要求：图片切换延迟 < 200ms
- 兼容性：iOS Safari、Android Chrome、微信内置浏览器
- Web Share API 降级：桌面端不支持时显示"下载"替代

## 4. 技术约束
- 技术栈：React 19 + Next.js 15 + TypeScript
- 不引入新依赖，纯前端实现
- 复用素材库已有的 `selectedIds` 多选状态

## 5. 边界情况
- 素材库为空时：不展示浏览器入口
- 桌面端不支持 Web Share API：分享按钮降级为下载按钮
- 图片 URL 为本地路径或远程 URL：分享前需 fetch 转为 File

## 6. 成功标准
- 素材库中任意图片可点击放大浏览
- 左右切换流畅，支持手势滑动
- 手机端能通过系统分享面板发送图片到微信
- 图片可下载到设备
