# Product Spec: 云端部署 — 手机 24 小时可用

## 1. 产品概述
- 解决的问题：电脑关机后手机无法访问小红书运营工具，需 24 小时可用
- 目标用户：铝单板销售从业者（自己 + 同事/客户，≤10 人）
- 核心价值：手机随时打开可用，不受电脑开关机限制

## 2. 功能需求

### 2.1 云端部署
- 功能描述：将现有工具部署到 Vercel，全球可访问
- 技术方案：Vercel 免费托管 + GitHub 自动部署
- 验收标准：
  - 手机浏览器访问部署域名，页面正常加载
  - 所有现有功能正常工作（素材库、内容管理、分类等）
  - 电脑关机后手机仍能访问

### 2.2 云数据库迁移
- 功能描述：从本地 SQLite 迁移到 Turso 云数据库
- 技术方案：Turso（SQLite 兼容，免费 9GB）
- 验收标准：
  - 现有数据（素材、内容、标签等）完整迁移到云端
  - 增删改查功能正常
  - 线上数据库与本地行为一致

### 2.3 图片存储适配
- 功能描述：图片上传改为云端存储
- 技术方案：评估后选择 Vercel Blob 或 Base64 存储
- 验收标准：
  - 新上传图片可在云端访问
  - 已有图片迁移后可正常显示
  - 图片加载速度可接受

### 2.4 邮箱验证码登录
- 功能描述：用户通过邮箱+验证码登录，保护工具不被外人访问
- 用户场景：打开网页 → 输入邮箱 → 收到验证码邮件 → 输入验证码 → 进入工具
- 技术方案：NextAuth.js v5 + Email Provider（免费）
- 验收标准：
  - 未登录用户无法访问任何页面
  - 输入邮箱后收到验证码邮件
  - 输入正确验证码后进入首页
  - 登录状态保持（Session 有效期 7 天）
  - 首次登录自动创建用户

### 2.5 用户管理
- 功能描述：管理谁能登录这个工具
- 用户场景：管理员邀请新用户、移除用户
- 验收标准：
  - 可在设置页查看已注册用户列表
  - 可手动添加/移除用户
  - 无权限用户无法登录

## 3. 非功能需求
- 可用性：24/7，99.9% 在线（Vercel SLA）
- 性能：首屏加载 < 3s（移动端 4G）
- 安全：登录验证码防暴力破解（5 次/小时限制）
- 兼容性：iOS Safari、Android Chrome、微信内置浏览器

## 4. 技术约束
- 技术栈：Next.js 15 + React 19 + TypeScript + Prisma + NextAuth v5
- 部署平台：Vercel（免费版）
- 数据库：Turso（SQLite 兼容）
- 认证：NextAuth v5 Email Provider
- 邮件发送：Resend（免费额度 100 封/天）
- 不引入新依赖之外的重构

## 5. 边界情况
- 免费额度超限：Vercel 100GB 带宽/月，Turso 9GB 存储，≤10 人够用
- 邮件发送失败：Resend 免费额度 100 封/天，超出后需付费
- 图片存储：现有图片量大时需评估存储方案
- 数据迁移失败：保留本地数据备份，可回滚

## 6. 成功标准
- 手机浏览器输入 URL → 看到登录页 → 输入邮箱验证码 → 进入工具
- 所有现有功能（素材库、内容管理、分类、分享）在云端正常使用
- 电脑关机后手机仍可正常使用
- 现有数据完整迁移，无丢失
