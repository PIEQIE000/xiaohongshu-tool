# 内容策略手册 — 铝单板工厂小红书运营

> 基于"三步法"方法论：获取信息 → 找角度 → 创作
> 核心理念：做内容的本质是讲故事，不是信息搬运

---

## 一、内容哲学

### 1.1 什么是内容（vs 信息搬运）

| 信息搬运（不写） | 内容（写这个） |
|-----------------|---------------|
| 铝单板价格优惠，欢迎咨询 | 一块铝板从铝锭到你墙上，中间被加了5次价 |
| 我厂拥有先进喷涂设备 | 我在喷涂车间站了3小时，回家咳了一晚上 |
| 木纹转印工艺介绍 | 甲方选了"胡桃木"色，3个月后褪色了，我告诉他为什么 |

**判断标准**：读者看完后，觉得世界跟看之前有一丁点不一样——这就是内容。

### 1.2 核心创作原则

1. **角度优先**：拿到一个选题，第一直觉想到的角度直接扔掉——那是所有人都会写的
2. **陌生化**：铝板谁没见过？换个角度让他重新认识一次
3. **弱者思维**：你不是行业大佬，你是个每天都在车间踩坑的小老板，真诚 > 装逼
4. **节奏感**：每篇内容要有起有伏，不能从头平到尾像说明书

## 二、角度库

### 2.1 工厂实拍类角度

| 平庸角度 | 反差角度 | 为什么更好 |
|---------|---------|-----------|
| "工厂实拍：我们的生产线" | "一块铝板的72小时：从铝锭到你墙上" | 有叙事弧线，不是展示设备 |
| "源头工厂，价格实惠" | "我算了一笔账：铝板价格里，材料费只占40%" | 用数据制造意外 |
| "开料→折边→焊接→打磨→喷涂" | "这家工厂最吵的不是机器，是质检员" | 人物角度，有温度 |
| "氟碳喷涂车间实拍" | "喷涂师傅说：你这颜色我调了3次才满意" | 具体的人和事 |
| "车间整洁，管理规范" | "昨天一块板子返工3次，我差点跟焊工打起来" | 真实冲突，不是摆拍 |

### 2.2 AI效果图类角度

| 平庸角度 | 反差角度 | 为什么更好 |
|---------|---------|-----------|
| "这种颜色的铝板真好看" | "这栋楼用了我们的铝板，3年后我专门去拍了张照" | 有时间纵深的叙事 |
| "多种颜色可选" | "客户选了32个颜色，只有这个颜色卖得最好" | 数据+筛选=价值 |
| "铝板外墙效果图" | "同样一栋楼，用铝板vs用涂料，5年后差距有多大" | 对比制造反差 |
| "推荐这种颜色搭配" | "最不建议选的3种铝板颜色（别问我怎么知道的）" | 避坑=信任 |

### 2.3 干货科普类角度

| 平庸角度 | 反差角度 | 为什么更好 |
|---------|---------|-----------|
| "铝单板厚度怎么选" | "游标卡尺测给你看：市面上标2.5mm的板，实际只有2.0" | 揭露真相=爆点 |
| "铝单板安装注意事项" | "安装师傅最恨的3种铝板设计（设计师请进来挨打）" | 制造对立=冲突=传播 |
| "氟碳喷涂vs粉末喷涂" | "我拿打火机烧了3块不同的板子，结果出乎意料" | 实验=可信 |
| "铝单板价格组成" | "一块300块的铝板，运费可能要100" | 意外信息点 |

### 2.4 发货展示类角度

| 平庸角度 | 反差角度 | 为什么更好 |
|---------|---------|-----------|
| "今日发货，满满的订单" | "这车货值20万，但司机压坏了3块我赔了2000" | 翻车=真实 |
| "木架打包，专线发货" | "为什么我坚持用木架？因为泡沫打包的亏我吃过" | 个人经历=信任 |
| "源头工厂，排期紧张" | "这周接了8个工地，能按时交货的只有5个" | 选择性=真实性 |

## 三、标题公式

### 3.1 标题必须做到：情理之中，预料之外

| 公式 | 示例 | 适用类型 |
|------|------|---------|
| 数字+反常识 | "铝板行业没人敢说的5个秘密" | 科普 |
| 对比式 | "同一栋楼，铝板vs真石漆，3年后变这样" | 效果图 |
| 幕后故事 | "一块铝板从车间到你墙上，经历了什么" | 工厂实拍 |
| 避坑式 | "选铝板最容易踩的3个坑，第2个90%人中招" | 科普 |
| 揭秘式 | "游标卡尺测给你看，你买的铝板真的够厚吗" | 科普 |
| 第一人称 | "我做铝板5年，这3种颜色真的不建议选" | 效果图 |

### 3.2 标题禁区

- 不要出现"欢迎咨询""价格优惠""厂家直销"
- 不要用感叹号超过2个
- 不要用"震惊""必看""速看"这类标题党词汇
- 标题里必须藏一个具体信息点（不能是虚的）

## 四、正文结构模板

### 4.1 工厂实拍叙事模板（sketch三番结构）

```
【封面】反差标题 + 车间实拍图

第一番（代入）：
一个具体场景，比如"下午3点，喷涂车间42度"

第二番（展开）：
一个意外信息，比如"这套设备200万，但最值钱的是老师傅的手"

第三番（升番）：
一个反转或金句，比如"客户问我为什么比别人贵5块/平方，
我带他走了一遍车间，他说值"

【收尾】固定话术钩子 + 标签
```

### 4.2 干货科普叙事模板

```
【封面】避坑式标题 + 对比图

第一番（痛点）：
"很多甲方第一次选铝板，都在这上面吃过亏"

第二番（拆解）：
具体知识点 + 数据 + 对比（普通vs正确）

第三番（升番）：
"更坑的是，有些供应商明明知道，但他不说"

【收尾】总结建议 + 钩子 + 标签
```

## 五、语言风格规范

### 5.1 人设定位

- **身份**：在工厂一线的老板/负责人，不是公司公关
- **语气**：像跟同行喝茶聊天，不像写产品手册
- **态度**：有观点，敢说真话，但尊重行业

### 5.2 用语规则

| 可以说 | 不能说 |
|--------|--------|
| "我们车间""我师傅" | "我司""本公司" |
| "说实话""坦白讲" | "保证""绝对""100%" |
| "我试过""我踩过坑" | "经过研究""据分析" |
| "大概""差不多" | "精准""严谨"（显得假） |
| 具体的数字和故事 | 形容词堆砌（高品质/卓越/一流） |

### 5.3 价值观底线

1. **不懂的工艺不要编**：不知道就说不知道
2. **不贬低同行**：可以说自己怎么做的，不说别人怎么烂的
3. **不碰敏感话题**：不聊政治、社会对立、地域歧视
4. **不制造焦虑**：不写"再不买就涨价了""限时"等套路
5. **承认局限性**：比如"我们确实做不了某些特殊工艺"
