# Dev Plan: 素材库图片浏览器 + 分享

## Phase 1: Lightbox 图片浏览器组件

### Task 1.1: 创建 Lightbox 基础组件
- 创建 `src/components/ImageLightbox.tsx`
- 接收 `images`, `currentIndex`, `onClose` props
- 实现全屏遮罩 + 居中显示图片
- **验证**：页面能打开全屏浏览器，显示当前图片

### Task 1.2: 左右切换
- 添加左右箭头按钮
- 点击切换上一张/下一张
- 首尾边界处理
- **验证**：点击箭头能切换图片，首尾时箭头禁用

### Task 1.3: 移动端手势滑动
- 添加 touch 事件处理（touchstart/touchmove/touchend）
- 滑动超过 50px 触发切换
- 切换动画过渡
- **验证**：手机端滑动能切换图片

### Task 1.4: 图片序号 + 键盘快捷键
- 显示当前序号（如 "3 / 12"）
- 桌面端支持键盘左右箭头切换
- 按 ESC 关闭
- **验证**：序号正确显示，键盘操作正常

## Phase 2: 分享 + 下载

### Task 2.1: 图片下载功能
- 全屏底部工具栏添加下载按钮
- fetch 图片转 blob 触发下载
- **验证**：点击下载按钮 → 图片保存到设备

### Task 2.2: Web Share 分享（单张 + 多张）
- 全屏浏览器底部工具栏添加分享按钮
- 调用 `navigator.share({ files: [...] })`
- 图片需先 fetch 转为 File 对象
- 桌面端不支持时降级为下载
- **验证**：手机端点击分享 → 系统分享面板弹出

### Task 2.3: 素材库多选分享
- 复用现有 selectedIds 多选状态
- 将"发送到手机"按钮改为"分享"按钮
- 多选后点击分享 → 批量分享图片
- **验证**：多选图片后系统分享面板弹出

## Phase 3: 集成

### Task 3.1: 集成到素材库页面
- 点击图片 → 打开 Lightbox（而非选择）
- 保留多选功能（通过长按或复选框）
- 移除旧的"发送到手机"分享链接弹窗
- **验证**：素材库页面完整交互流程正常
